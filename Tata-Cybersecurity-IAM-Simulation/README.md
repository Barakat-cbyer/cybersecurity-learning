# Tata Cybersecurity IAM Simulation

## Overview

I completed the Tata Cybersecurity Analyst Virtual Job Simulation on Forage, with a focus on Identity and Access Management (IAM).

The simulation involved assessing the IAM readiness of a fictional global organisation, designing IAM solutions, and developing an implementation plan for integrating an IAM platform.

## What I Worked On

During the simulation, I worked on:

- IAM readiness assessment
- User lifecycle management
- Joiner-Mover-Leaver processes
- Role-Based Access Control (RBAC)
- Principle of Least Privilege
- Multi-Factor Authentication (MFA)
- Single Sign-On (SSO)
- Access governance
- IAM platform integration
- Legacy system and cloud integration
- IAM implementation planning

## What I Learned

I learned how organisations manage digital identities and control access to systems and resources.

I also learned how IAM supports cybersecurity by ensuring that users receive the correct level of access based on their roles and responsibilities.

The simulation helped me understand how IAM connects with SOC operations, especially when investigating suspicious logins, account compromise, privilege changes, and unauthorised access.

## Result

I completed the simulation and scored **8/10** on the overall knowledge assessment.
